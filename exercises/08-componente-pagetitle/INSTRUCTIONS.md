# Exercício 08 — Componente PageTitle

## Objetivo

Criar um componente simples que renderiza o título da página do painel.

## Checklist

1. Criar o arquivo `PageTitle.tsx` dentro de `src/components`.
2. Declarar a função com `Pascal Case`.
3. Criar a interface `PageTitleProps` (individual props): `title: string`.
4. Renderizar o título em um `<h1>` estilizado com Tailwind.
5. Importar e usar na `App.tsx`.

## Resultado esperado

Um componente `PageTitle` reutilizável renderizando o título do painel.
