# Exercício 02 — Instalar Tailwind CSS

## Objetivo

Instalar e configurar o Tailwind CSS em um projeto Vite + React já existente, seguindo o tutorial oficial, sem reinstalar o Vite.

## Observação importante

O primeiro passo do tutorial (criar o projeto Vite) **não deve ser seguido**, pois o projeto já foi criado no exercício anterior. O passo "5" da instalação também **não deve ser seguido**.

## Checklist

1. Aceder ao [tutorial oficial do Tailwind para Vite](https://tailwindcss.com/docs/installation/using-vite).
2. Instalar o Tailwind CSS com `npm install tailwindcss @tailwindcss/vite`.
3. Configurar o plugin do Tailwind em `vite.config.ts`.
4. Adicionar o `@import` do Tailwind no `index.css` preparado no exercício anterior.
5. Testar que o Tailwind funciona usando uma utility-class em uma `div`, por exemplo `bg-red-500`.

## Resultado esperado

Um projeto Vite com Tailwind CSS configurado e 100% funcional, sem erros no `dev` nem no `build`.

## Entregáveis

- Projeto configurado conforme o enunciado.
- `RESULT.md` preenchido com suas próprias palavras.
- Commit e push.
