# Exercício 04 — Global types & interfaces

## Objetivo

Criar um arquivo de tipos e interfaces globais no React, responsável por organizar os types e interfaces de maneira que possam ser reutilizados.

## Checklist

1. Criar uma pasta `utils` dentro de `src`.
2. Dentro de `utils`, criar o arquivo `types.d.ts`.

## Resultado esperado

Um arquivo `types.d.ts` global, organizando types e interfaces reutilizáveis para o projeto.
