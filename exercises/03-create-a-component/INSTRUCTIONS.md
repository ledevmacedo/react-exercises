# Exercício 03 — Criar um componente de card

## Objetivo

Criar um componente chamado `Card` que receberá como única prop o `children`.

## Checklist

1. Criar uma pasta `components` dentro de `src`.
2. Criar o arquivo do componente de card seguindo o padrão `Camel Case`.
3. Declarar a função que cria o componente com `Pascal Case`.
4. Criar uma interface e atribuí-la à prop no parâmetro da função.
5. Estilizar o componente com Tailwind ao seu gosto (proibido usar IA).
6. Importar o componente na `App.tsx` e colocar o `hello world` dentro dele.

## Resultado esperado

Um componente `Card` reutilizável, estilizado com Tailwind, recebendo `children` e renderizando o `hello world` na `App`.
