# Exercício 07 — Instalar solar-icons/react

## Objetivo

Instalar e configurar o pacote de ícones `solar-icons/react` para uso nos indicadores das viagens.

## Checklist

1. Instalar o pacote com `npm install @solar-icons/react` (ou equivalente indicado pelo formador).
2. Importar e renderizar um ícone de teste na `App` para confirmar que funciona.
3. Confirmar que o `build` roda sem erros.

## Resultado esperado

Pacote de ícones instalado e funcional no projeto.

## Entregáveis

- Projeto configurado conforme o enunciado.
