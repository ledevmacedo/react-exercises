# Exercise 03 — Create a card component

## Objective

Create a component called `Card` that will receive `children` as its only prop.

## Checklist

1. Create a `components` folder inside `src`.
2. Create the card component file following the `Camel Case` pattern.
3. Declare the function that creates the component using `Pascal Case`.
4. Create an interface and assign it to the prop in the function parameter.
5. Style the component with Tailwind to your taste (using AI is forbidden).
6. Import the component in `App.tsx` and place the `hello world` inside it.

## Expected result

A reusable `Card` component, styled with Tailwind, receiving `children` and rendering the `hello world` in the `App`.
