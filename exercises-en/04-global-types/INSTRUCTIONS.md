# Exercise 04 — Global types & interfaces

## Objective

Create a global types and interfaces file in React, responsible for organizing types and interfaces so they can be reused.

## Checklist

1. Create a `utils` folder inside `src`.
2. Inside `utils`, create the `types.d.ts` file.

## Expected result

A global `types.d.ts` file, organizing reusable types and interfaces for the project.
