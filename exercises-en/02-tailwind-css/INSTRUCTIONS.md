# Exercise 02 — Install Tailwind CSS

## Objective

Install and configure Tailwind CSS in an existing Vite + React project, following the official tutorial, without reinstalling Vite.

## Important note

The first step of the tutorial (creating the Vite project) **should not be followed**, since the project was already created in the previous exercise. Step "5" of the installation **should not be followed** either.

## Checklist

1. Access the [official Tailwind tutorial for Vite](https://tailwindcss.com/docs/installation/using-vite).
2. Install Tailwind CSS with `npm install tailwindcss @tailwindcss/vite`.
3. Configure the Tailwind plugin in `vite.config.ts`.
4. Add the Tailwind `@import` to the `main.css` prepared in the previous exercise.
5. Test that Tailwind works using a utility class on a `div`, for example `bg-red-500`.

## Expected result

A Vite project with Tailwind CSS configured and 100% functional, with no errors in `dev` or `build`.

## Deliverables

- Project configured according to the instructions.
- `RESULT.md` filled in with your own words.
- Commit and push.

- Note in `RESULT.md` any errors found and how you solved them.
