# Exercise 08 — PageTitle component

## Objective

Create a simple component that renders the panel's page title.

## Checklist

1. Create the `PageTitle.tsx` file inside `src/components`.
2. Declare the function using `Pascal Case`.
3. Create the `PageTitleProps` interface (individual props): `title: string`.
4. Render the title in an `<h1>` styled with Tailwind.
5. Import and use in `App.tsx`.

## Expected result

A reusable `PageTitle` component rendering the panel title.
