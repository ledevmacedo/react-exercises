# Exercise 01 — Create a React app with Vite

## Objective

Create a React project from scratch using Vite as the bundler, understanding the generated structure and the basic development workflow.

## Checklist

1. Install Vite with the default command suggested in the official documentation.
2. Run `npm install` and confirm everything works.
3. Remove the unnecessary files from the project.

## Expected result

A clean Vite project, with nothing in the app besides a **"hello world"**, no unused files, CSS imports or HTML that comes with Vite and is not needed. The cleanup should follow what was taught in class and in the `.md` manual sent by the instructor.

## Deliverables

- Project created according to the instructions.
- `RESULT.md` filled in with your own words.
- Commit and push.

## Tips

- Read the official Vite documentation before starting.
- Note in `RESULT.md` any errors found and how you solved them.
